# R.A.V.E. Camp

R.A.V.E. Camp is the official event website for a six-day youth leadership
experience built around **Recharge, Adjust, Vibe, and Engage**. It introduces
prospective campers to the programme, speakers, activities, pricing, and venue,
while providing clear paths to register and explore previous camp moments.

The experience brings young leaders together for learning, worship, connection,
and personal growth. Camp activities include expert-led sessions, interactive
workshops, Model United Nations, team competitions, games, and exposure to
robotics and technology.

## Website features

- Responsive event landing page with light and dark themes
- Camp overview, programme information, speakers, pricing, and sponsors
- Registration calls to action
- Photo gallery and participant testimonials
- Interactive R.A.V.E. Camp highlight video
- Event date and venue information

## Tech stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Radix UI and Material UI components

## Local development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
